# Kaleidoscope Glyph: version history

Each file here is a complete, working copy of `glyph.html` as it looked at that moment.
Double-click any of them to open it in a browser (they work offline). Glyphs saved with
one version can be opened by the others (older versions just ignore newer extras such as picture styles).

The live, current page is always `../glyph.html`. Git also keeps every change (the "commit" column).

## Adding a new version
Copy `glyph.html` to `versions/glyph-vN-YYYY-MM-DD-short-name.html` and add a row above.
